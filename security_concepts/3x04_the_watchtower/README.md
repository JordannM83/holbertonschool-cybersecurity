Learning Objectives
By the end of this project, you are expected to be able to explain to anyone, without the help of Google:

Why Centralized Logging is critical for Non-Repudiation and Forensics.

How to configure rsyslog to send and receive logs over the network.

The structure of standard Linux logs (auth.log, syslog, apache2/access.log).

How to use Regex (Regular Expressions) to extract IP addresses and Usernames from logs.

The difference between a False Positive and a True Positive in alerting.

The concept of Log Correlation (connecting two separate events).

How to configure Logrotate to prevent disk saturation.

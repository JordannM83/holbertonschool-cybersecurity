Learning Objectives
By the end of this project, you will be able to explain to anyone, without the help of Google:

Core Competencies
The Linux Filesystem Hierarchy - What lives in /etc, /var, /home, /usr, and why it matters for security

The Permission Model - How rwx bits work for User, Group, and Others, and what each combination actually allows

Octal vs. Symbolic Notation - Converting between chmod 755 and chmod u=rwx,go=rx fluently

The Special Bits - What SUID, SGID, and Sticky Bit do, and why SUID on the wrong binary is a critical vulnerability

Operational Skills
Remote Workflow - Managing servers exclusively through SSH/SCP without interactive access

Precision Searching - Using find with complex criteria (type, size, time, permissions) to locate specific files

Pattern Matching - Using grep and regular expressions to extract information from files

Access Control Lists (ACLs) - Granting granular permissions beyond the traditional owner/group/other model

Security Mindset
Audit Before You Fix - Why blind remediation is dangerous and how to assess before acting

Least Privilege - The principle that users and processes should have minimum necessary permissions

Defense in Depth - Why permissions are one layer in a multi-layered security strategy

Learning Objectives
By the end of this project, you are expected to be able to explain to anyone, without the help of Google:

Container Security Fundamentals:

How Docker isolation works (namespaces, cgroups)

Why running as root in containers is dangerous

What container escape means and common techniques

The difference between image security and runtime security

Dockerfile Security:

How to choose secure base images

Why multi-stage builds improve security

How to create and use non-root users in containers

How to handle secrets without hardcoding them

The principle of minimal images

Runtime Security:

What Linux capabilities are and which to drop

How to use read-only filesystems

How to set resource limits (CPU, memory)

How to configure security options (no-new-privileges, seccomp)

Security Auditing:

How to use docker-bench-security

How to interpret and act on audit findings

Common CIS Docker Benchmark controls

Practical Application:

How to build a secure development environment

How to balance security with developer experience

How to document container security policies

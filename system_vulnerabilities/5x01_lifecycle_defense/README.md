Learning Objectives
By the end of this project, you are expected to be able to explain to anyone, without the help of Google:

System Recovery:

How to diagnose and resolve dpkg/apt lock issues

How to repair packages in "half-configured" or broken states

How to validate and clean APT source configurations

Patch Management:

The difference between security updates and feature updates

How unattended-upgrades works and how to configure it

How to create package blacklists for critical services

How to schedule maintenance windows for automatic updates

How to configure automatic reboot policies for kernel updates

Crisis Management:

How to identify which package caused a regression

How to rollback a package to a previous version

How to place holds on packages and manage exceptions

The risks of package holds and how to track them

Professional Documentation:

How to write a Patch Management Policy

How to document incident response procedures

How to create remediation reports for stakeholders

Learning Objectives
By the end of this project, you are expected to be able to explain to anyone, without the help of Google:

How to consume REST APIs using Python (requests vs aiohttp).

The difference between Synchronous (blocking) and Asynchronous (non-blocking) I/O.

How to parse JSON responses from complex API structures.

How to Wrap external binary tools (like Nmap) using subprocess.

The concept of Data Enrichment in cybersecurity.

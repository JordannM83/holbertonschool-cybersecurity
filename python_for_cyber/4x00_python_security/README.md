Learning Objectives
By the end of this project, you are expected to be able to explain to anyone, without the help of Google:

Why Virtual Environments (venv) are mandatory for security projects.

The difference between sys.argv and argparse.

How to use try/except blocks to prevent crashes and information leakage.

Why Context Managers (with open...) are critical for file handling.

How to structure a Python project (if __name__ == "__main__":).

The difference between Hashing and Encryption.

How to write basic Unit Tests to validate your logic.

Learning Objectives
By the end of this project, you are expected to be able to explain to anyone, without the help of Google:

How the TCP Three-Way Handshake relates to socket programming (connect vs syn).

The difference between a Blocking and Non-Blocking socket.

Why Multi-threading is critical for network scanning speed.

What Banner Grabbing is and why it's useful for reconnaissance.

How to handle socket Timeouts and exceptions gracefully.

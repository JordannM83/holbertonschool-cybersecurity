Learning Objectives
By the end of this project, you are expected to be able to explain to anyone, without the help of Google:

How to use Scapy to sniff and dissect packets.

The difference between a Callback function and a loop in sniffing.

How to implement BPF Filters (Berkeley Packet Filter).

Why Object-Oriented Programming (OOP) improves maintainability for complex tools.

The basics of Unit Testing for network code.

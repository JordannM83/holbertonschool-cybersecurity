# Lumen Industrial Systems — PTES Engagement

This directory contains the auditable deliverables for the Lumen Industrial Systems penetration test, conducted under the Penetration Testing Execution Standard (PTES).

The Rules of Engagement must be signed by Lumen and Vanguard Security before any active testing begins. The signed asset register is authoritative: no hostname, IP address, API endpoint, administrative panel, gateway, or MQTT topic may be tested until it is explicitly identified as in scope.

## Deliverables

- [1-rules_of_engagement.md](1-rules_of_engagement.md) — engagement boundary, operating rules, contacts, stop conditions, and post-engagement obligations.
